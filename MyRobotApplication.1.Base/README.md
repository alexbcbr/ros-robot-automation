Catkin template for ROS Workspace
============================================== 
 
This structure was based in Robomaker documentation
https://docs.aws.amazon.com/robomaker/latest/dg/application-create-new.html

Environment
-------------------------------- 
 
1. Create the build and ros bundle
 
        $ cd MyRobotApplication.1.Base/robot_ws/src/robot_app
        $ ./build+bundle.sh 
 
2. Launching from command line: 
 
        $ ./run.sh
